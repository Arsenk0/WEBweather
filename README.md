# 🌦️ WeatherUA Pro — Імерсивний Дашборд Погоди

**WeatherUA Pro** — це сучасний, преміальний веб-додаток для моніторингу погоди в Україні, що поєднує в собі високу точність даних та естетику Glassmorphism. Додаток розроблений для надання вичерпної метеорологічної інформації в елегантному та інтуїтивно зрозумілому інтерфейсі.

## ✨ Основні можливості

- 🌍 **Геолокація та Пошук**: Автоматичне визначення місцезнаходження або пошук будь-якого міста України.
- 📊 **Детальні Метрики**: Температура, відчуття, вологість, швидкість вітру, тиск, точка роси та UV-індекс.
- ⏱️ **Погодинний Прогноз**: Візуалізація змін погоди на найближчі 24 години.
- 📅 **Прогноз на 7 днів**: Короткий огляд погодних умов на тиждень вперед.
- 🍃 **Якість Повітря (AQI)**: Детальний аналіз забруднення повітря (PM2.5, PM10, NO₂, O₃, CO, SO₂).
- 🔭 **Астрономія**: Час сходу та заходу сонця, тривалість світлового дня та фази місяця.
- 🧥 **Стиль життя**: Розумні поради щодо одягу, миття авто та захисту від сонця.
- 🗺️ **Радар Опадів**: Інтерактивна карта опадів у реальному часі на базі RainViewer.
- ⌨️ **Гарячі клавіші**: Швидкий доступ до пошуку за допомогою `⌘K` або `/`.

## 🛠️ Технологічний стек

- **Core**: HTML5, CSS3 (Custom Properties, Glassmorphism).
- **Logic**: Vanilla JavaScript (ES6+), Vite.
- **Maps**: Leaflet.js & RainViewer API.
- **Data**: Open-Meteo API (High-resolution weather data).
- **Icons**: Lucide Icons.
- **Typography**: Outfit (Google Fonts).

## 🚀 Як запустити проект

1. **Клонуйте репозиторій**:
   ```bash
   git clone https://github.com/your-username/weather-ua.git
   ```

2. **Встановіть залежності**:
   ```bash
   npm install
   ```

3. **Запустіть сервер розробки**:
   ```bash
   npm run dev
   ```

4. Відкрийте браузер за адресою `http://localhost:5173`.

## 🎨 Дизайн та Анімація

Додаток використовує сучасний підхід **Glassmorphism**, що забезпечує ефект матового скла. Динамічний фон змінюється залежно від погодних умов, а плавні мікро-анімації роблять взаємодію з інтерфейсом живою та приємною.
